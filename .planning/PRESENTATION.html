Asset Book-In App

Slattery Auctions · assetbookintool.com

Built outside work hours. In production. Saving time now.
Photographs an asset on site → AI extracts every Salesforce field and writes the auction description → staff review and paste. Done.

How It Works

  • Photograph the asset — compliance plate, build plate, odometer, instrument cluster, exterior
  • Upload to the app — runs on any phone, no install
  • AI reads the plates, extracts every field, infers specs from model knowledge, writes the description
  • Review step — confirm extracted data, fix anything, type plain English extras ("no keys, bull bar, purple")
  • Copy All — one button copies all Salesforce fields + description to clipboard, ready to paste
  • With API access: direct push to Salesforce, no clipboard step
